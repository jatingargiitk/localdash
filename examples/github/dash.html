Daily GitHub activity for the past year: stars, forks, issues and traffic. KPIs compare the last 30 days with the 30 days before.

New stars (last 30 days)

 
DuckDB SQL
WITH a AS (SELECT max(date) AS d FROM github_stars)
SELECT
  sum(new_stars) FILTER (WHERE date > d - INTERVAL 30 DAY) AS stars,
  sum(new_stars) FILTER (WHERE date <= d - INTERVAL 30 DAY AND date > d - INTERVAL 60 DAY) AS stars_prev
FROM github_stars, a

Net new open issues (last 30 days)

 
Issues opened minus issues closed.
DuckDB SQL

Cumulative stars and forks gained

Running total since the start of the data (the CSV has no starting totals).

DuckDB SQL
SELECT
  date,
  sum(new_stars) OVER (ORDER BY date) AS stars,
  sum(new_forks) OVER (ORDER BY date) AS forks
FROM github_stars
ORDER BY date

Weekly new stars and forks

DuckDB SQL
SELECT
  date_trunc('week', date) AS week,
  sum(new_stars) AS new_stars,
  sum(new_forks) AS new_forks
FROM github_stars
GROUP BY 1
ORDER BY 1

Weekly issues opened vs closed, PRs merged

DuckDB SQL
SELECT
  date_trunc('week', date) AS week,
  sum(issues_opened) AS issues_opened,
  sum(issues_closed) AS issues_closed,
  sum(prs_merged) AS prs_merged
FROM github_stars
GROUP BY 1
ORDER BY 1

Open issue backlog growth

Cumulative issues opened minus closed since the start of the data.

DuckDB SQL
